About this prototype

This is the full final-system interface for Hiltown Hotel Sylhet — all 50 rooms across 5 floors. Every control is interactive so you can preview the complete experience. In the current prototype, Room 101's air-conditioner is wired to real hardware through ESP32 + Blynk; all other controls run in simulation until each device is integrated. After the deal is confirmed, MQTT, Firebase and the remaining appliances go live with no change to this interface.
